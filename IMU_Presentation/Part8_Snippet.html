Part 8: Real-Time Testing System

This section demonstrates the live deployment of the trained model using a WebSocket-based architecture for low-latency inference.

1. System Architecture

  • 📱 Mobile Phone (Sensor Website): Collects accelerometer data and sends it via secure WebSocket.
  • 🖥️ PC (Streamlit Viewer): Receives real-time data, runs the classification model, and visualizes results.
  • 💾 CSV Recording: Optional features to buffer and save session data for analysis.

2. Key Technical Improvements

  • WebSocket Protocol: Replaced HTTP POST to eliminate request overhead (< 100ms latency).
  • SSL/HTTPS: Implemented self-signed certificates to access mobile sensor APIs.
  • UDP Forwarding: Used for fast local network data transfer between components.
  • Dynamic Confidence: Model certainty ranges from 75% to 99% based on signal clarity.

3. CSV Recording Features

  • Toggle recording on/off dynamically during the session.
  • Real-time buffer counter display (limit: 50,000 samples).
  • Automatic timestamping for every sample.
  • activity predictions included in the downloaded CSV.
